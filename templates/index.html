🔑 API Access

Use this endpoint to download videos programmatically.

GET https://YOUR-DOMAIN/api/v1/download
?api_key=YOUR_KEY
Authorization: Bearer YOUR_KEY
x-api-key: YOUR_KEY
url       = YouTube video URL (required)
format    = mp4 | mp3        (default: mp4)
quality   = 720p | 1080p ... or 128kbps | 192kbps ...
info_only = 1 (return metadata only, no file)
curl -L -o video.mp4 \
  "https://YOUR-DOMAIN/api/v1/download?api_key=YOUR_KEY&url=https://youtu.be/VIDEO_ID&format=mp4&quality=720p"
