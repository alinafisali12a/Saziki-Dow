POST /api/v1/video_info

Fetch metadata (title, author, duration, views, thumbnail) for a given YouTube URL.

# Fetch video metadata
curl -X POST https://YOUR-APP.up.railway.app/api/v1/video_info \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://youtu.be/VIDEO_ID"}'
// Fetch video metadata
const res = await fetch("https://YOUR-APP.up.railway.app/api/v1/video_info", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ url: "https://youtu.be/VIDEO_ID" }),
});
const data = await res.json();
# Fetch video metadata
import requests

r = requests.post(
    "https://YOUR-APP.up.railway.app/api/v1/video_info",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={"url": "https://youtu.be/VIDEO_ID"},
)
print(r.json())

POST /api/v1/download

Stream the selected video or audio. Returns the raw binary (attachment).
Parameters: url, format (mp4/mp3), quality (e.g. "720p", "320kbps"). 

curl -L -o video.mp4 \
  "https://YOUR-APP.up.railway.app/api/v1/download?url=https://youtu.be/VIDEO_ID&format=mp4&quality=720p&api_key=YOUR_API_KEY"
const url = "https://YOUR-APP.up.railway.app/api/v1/download"
  + "?url=" + encodeURIComponent("https://youtu.be/VIDEO_ID")
  + "&format=mp4&quality=720p"
  + "&api_key=YOUR_API_KEY";
window.location.href = url;
import requests
r = requests.get(
    "https://YOUR-APP.up.railway.app/api/v1/download",
    params={
        "url": "https://youtu.be/VIDEO_ID",
        "format": "mp4",
        "quality": "720p",
        "api_key": "YOUR_API_KEY",
    },
    stream=True,
)
with open("video.mp4", "wb") as f:
    for chunk in r.iter_content(8192):
        f.write(chunk)

Authentication

Provide your API key in any of these ways:

  • Query parameter: ?api_key=YOUR_KEY
  • Bearer header: Authorization: Bearer YOUR_KEY
  • Custom header: x-api-key: YOUR_KEY
